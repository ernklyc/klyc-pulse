# Güvenlik / Security

KLYC-Pulse yönetici yetkisiyle çalışır ve donanım ayarlarını değiştirir. Bu nedenle:

- Yalnızca resmi sürüm sayfasından indirdiğiniz ya da kendiniz derlediğiniz sürümü çalıştırın; dosyanın SHA-256 özetini `SHA256SUMS.txt` ile karşılaştırın.
- Uygulama Windows Defender, Bellek Bütünlüğü gibi güvenlik ayarlarına dokunmaz, çekirdek sürücüsü yüklemez ve veri toplamaz.

## Güvenlik açığı bildirimi / Reporting a vulnerability

Herkese açık sorun (issue) **açmayın**. GitHub'ın **Security → Report a vulnerability** (özel bildirim) özelliğini kullanın. Lütfen etkilenen sürümü, adımları ve etkiyi yazın. / Please do **not** open a public issue; use GitHub's private vulnerability reporting.
